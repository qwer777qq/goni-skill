# Aside 다계정 설정 안내

## 세 가지 계정을 구분하세요

| 구분 | 의미 |
|---|---|
| Aside 계정 | CLI에서 u0, u1 등으로 선택하는 Aside 작업 공간 |
| 브라우저 프로필 | 사이트별 로그인·쿠키가 분리되는 브라우저 환경 |
| 포털 로그인 | 그 프로필 안에서 로그인한 네이버·Google 등 사이트 계정 |

Chrome의 Google 동기화 로그인, Aside 앱 로그인, 웹사이트 Google 로그인은 같은 작업이 아닙니다. 네이버 이용을 위해 Google 동기화를 켜야 하는 것은 아닙니다.

## 예시 구성

| 프로필 별칭 | 용도 | 프로필 안에서 로그인할 계정 |
|---|---|---|
| 스타·연예인 | 연예 콘텐츠 탐색·소통 | 해당 카테고리 네이버 계정 |
| 카페·블로그 | 강의·블로그 운영 | 해당 업무 네이버 계정 |
| 매장 운영 | 매장 정보·소식 관리 | 매장 네이버 계정 |

다른 네이버 계정을 동시에 쓰려면 브라우저 프로필을 나누세요. 같은 네이버 계정을 여러 프로필에서 사용해도 추천 학습까지 분리된다고 보장할 수 없습니다.

## 설정 순서

1. Aside 앱에서 사용할 브라우저 프로필을 만들거나 선택합니다. 이름을 카테고리와 기대 계정으로 알아보기 쉽게 지정합니다. 앱 버전에 따라 메뉴 위치가 달라지므로 현재 화면을 확인합니다.
2. 각 프로필에서 네이버를 열고 해당 계정으로 로그인합니다. Google 등 다른 포털도 필요할 때 그 프로필 안에서 로그인합니다.
3. 로그인 정보는 앱의 인증 화면에서 입력합니다. 공유 문서·스킬·설정 JSON·GitHub에 비밀번호를 넣지 않습니다.
4. MY/계정 화면에서 실제 네이버 ID를 확인합니다. 프로필 이름만으로 로그인 계정을 판단하지 않습니다.
5. CLI에서 연결을 확인합니다.

```powershell
& 'C:/설치경로/aside.exe' account list
& 'C:/설치경로/aside.exe' --account u0 host profiles --json
& 'C:/설치경로/aside.exe' --account u1 host profiles --json
```

6. 실제 확인한 계정·프로필 ID를 매핑합니다.

```powershell
python scripts/community.py profile --name star --account u0 --profile-id "확인한-프로필-ID" --naver-id "확인한-네이버-ID" --category "스타·연예인"
python scripts/community.py repl-command --name star --aside "C:/설치경로/aside.exe"
```

7. 출력된 인자로 지속형 REPL을 열고 현재 탭부터 확인합니다.

```javascript
console.log(await listBrowserTabs())
```

기존 탭이 있으면 실제 targetId로 연결하고, 없으면 네이버를 엽니다.

```javascript
await openTab('https://m.naver.com')
console.log((await snapshot(page, {interactive:true})).tree)
```

## 사용 요청 예시

> 고니 네이버 품앗이 스킬로 star 프로필의 실제 네이버 계정을 확인해 줘. 스타·연예인 관련 블로그 글을 읽고 관련 있는 후보 3개를 보여 줘. 이미 공감하거나 댓글을 쓴 글은 제외하고, 각 글 내용에 맞는 댓글을 준비해 줘.

실행까지 원하는 경우 계정·카테고리·동작·건수를 명시합니다.

> 확인한 star 프로필에서 후보 중 관련성이 가장 높은 글 한 개에 공감하고, 본문을 읽은 감상 댓글 한 개를 작성해 줘. 결과 화면과 URL을 보여 주고 중복 기록을 남겨 줘.

## 자주 생기는 문제

- 프로필이 목록에 없음: `account list`의 다른 Aside 계정도 확인합니다.
- `signed out`: Aside 로그인과 로컬 프로필 연결 여부를 각각 확인합니다.
- 엉뚱한 네이버 계정: 실행을 중단하고 지정 프로필을 다시 확인합니다. 다른 업무 계정을 로그아웃시키지 않습니다.
- Codex 내부 브라우저에서 로그인 안 됨: Aside 프로필의 로그인 정보가 자동 공유되는 것은 아닙니다.
- 보안 확인: 사용자가 사이트 안내에 따라 직접 확인합니다. 자동 우회하거나 다른 계정으로 이어서 수행하지 않습니다.
