# 고니 네이버 블로그 품앗이

## 시작

- 다계정 설정을 안내할 때 [사용자 안내](references/multi-account-guide.md)를 읽는다.
- 이 스킬은 Aside CLI와 실제 화면을 사용하는 에이전트 워크플로다. Python CLI는 프로필 매핑·작업 큐·중복 기록을 담당하며 단독으로 댓글을 게시하지 않는다.
- 최신 사용자 요청에서 카테고리·계정·실행 범위를 정한다. 프로젝트 제작 요청만으로 실제 게시 권한을 추정하지 않는다. 이미 허가받은 범위는 반복 확인하지 않는다.
- 비밀번호·인증코드·쿠키·토큰은 설정, 기억, 로그, 공개 저장소에 저장하지 않는다. 프로필 별칭과 공개 계정 식별자만 로컬에 둔다.

## 프로필 선택

1. `aside --help`, `aside guide repl`, `aside skills list`로 현재 사용법을 확인한다. Google 서비스에 접근할 때 google-accounts 내장 스킬을 먼저 읽는다.
2. `aside account list`, 각 `aside --account <account> host profiles --json`으로 연결 상태를 확인한다. signed out인 Aside 계정도 로컬 프로필이 연결되어 있을 수 있다.
3. 계정과 프로필을 모두 명시한다. 원하는 프로필이 없으면 다른 업무 계정으로 대체하거나 로그아웃하지 않는다.
4. `listBrowserTabs()`로 현재 탭을 조회하고 해당 탭을 연결한다. 없으면 `openTab('https://m.naver.com')`. 프로필 이름과 실제 사이트 로그인은 별개이므로 MY/계정 화면에서 대상 네이버 ID를 확인한다.
5. 알려진 CLI 경로는 `C:/Users/USER/AppData/Local/Aside/CLI/versions/win-x64/1.26.1019.1018/aside.exe`다. 경로가 없으면 설치된 공식 서명 실행파일을 확인한다.

## 탐색과 반응

- 지속형 `aside ... repl`에서 실행한다. 단발 REPL의 임시 탭은 종료될 수 있다.
- `snapshot()`으로 홈판·클립·블로그 본문을 읽고 사용자의 카테고리와 맞는 대상을 고른다. 실제 읽은 내용으로 댓글을 작성한다. 직접 경험하지 않은 일을 경험했다고 쓰지 않는다.
- 블로그 글과 클립은 별도 화면으로 취급한다. 관찰하지 않은 URL·선택자·ref를 추측하지 않는다. ref는 새 snapshot마다 갱신한다.
- 공감은 이미 선택됐는지 확인한다. 댓글·서이추는 기존 기록과 화면에서 중복 여부를 확인한다.
- 동일 콘텐츠에 대한 여러 계정의 반복 반응을 자동으로 조직하지 않는다. 계정마다 사용자가 지정한 카테고리와 업무 범위를 유지한다.
- 요청받은 동작만 수행하고, 동작 후 새 snapshot으로 실제 반영을 확인한다. 타임아웃이나 모호한 결과는 `uncertain`으로 기록하고 재전송 전에 화면을 확인한다.
- 보안 확인·로그인 만료·계정 불일치·사이트 제한이 나오면 해당 프로필 작업을 멈춘다. 다른 계정으로 전환해 제한을 회피하지 않는다.
- 추천 화면 변화와 내 글 노출 성과는 별도로 관찰한다. 노출 상승을 보장하지 않는다.

## CLI와 기록

`scripts/community.py --state <로컬 상태 폴더> <명령>`을 사용한다.

- `profile --name <별칭> --account <Aside계정> --profile-id <ID> --naver-id <ID> --category <분류>`: 계정 매핑.
- `profiles`: 매핑 조회.
- `add --name <별칭> --url <실제 확인 URL> --action like|comment|neighbor --note <본문 근거>`: 중복을 확인해 작업 추가.
- `next --name <별칭>`: 다음 대기 작업 조회.
- `record --id <작업ID> --status done|skipped|uncertain --evidence <확인한 결과>`: 결과 기록.
- `repl-command --name <별칭> --aside <실행파일>`: 해당 프로필의 지속형 REPL 실행 인자 출력.

상태 폴더 기본값은 사용자 홈 `.goni-naver-community`다. 완료·불확실 작업은 자동 재등록하지 않는다. 댓글 문구는 사용자에게 보여 줄 작업 보고서에 정리하고, 계정 인증값이나 타인의 불필요한 개인정보는 수집하지 않는다.

## 화면 공유와 보고

Aside의 프로필 로그인과 Codex 내부 브라우저 로그인은 공유된다고 가정하지 않는다. 사용자가 Codex 내부 화면을 요구하면 실제 로그인된 작업 화면을 표시할 수 있는지 먼저 확인하고, 불가능하면 Aside 실화면과 내부 진행 보고서를 구분해 설명한다.

보고에는 프로필 별칭, 카테고리, 대상 URL, 수행 동작, 검증 결과, 남은 항목을 포함한다. 성공한 동작만 완료로 표시한다.
