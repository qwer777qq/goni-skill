# AlphaCut 관찰 기준 — 2026-10-17

한국어 UI의 `/my_project`, `/template`, 실제 생성 프로젝트와 편집기에서 확인한 내용이다. 현재 서비스 동작은 다시 확인한다.

- 추천 템플릿은 화면 DOM에 136장 렌더링되었고, 모바일·데스크톱 중복을 제거하면 고유 미리보기 68종이었다. 분류별 고유 수는 깔끔 9, SNS·앱 화면 9, 종이 질감 7, 노트·메모 14, 귀여운·파스텔 9, 어두운·감성 11, 밝은·화사 9였다.
- 공개 프런트엔드 번들에서 68개 한국어 preset tag와 설정 객체 원문을 확인했다. 55개는 정적 JSON5로 파싱 가능했고, 13개는 계산식이 있어 원문을 보존했다. 이는 서버 데이터의 완전한 목록을 증명하지 않는다.
- 링크 입력과 MP4/MOV/WEBM/MKV 업로드, AI 하이라이트·REMIX+·수동 생성, 길이 선택, AI 요청, SRT/VTT 첨부, 범위 선택 UI를 확인했다.
- 편집기는 제목·채널·원본 제목·레이아웃·자막·요소 탭을 제공했다. 자막에는 활성화, 검색·바꾸기, 줄 수, 폰트·색·배경·테두리·자간·애니메이션, TXT/SRT 내보내기가 있었다.
- 요소에는 이미지·비디오·오디오·텍스트·댓글·모자이크, 배경에는 없음·색상·이미지·유리 옵션이 보였다. 고급 오디오와 아웃트로 추가에는 Pro 안내가 있었다.
- 사용자가 제공한 유튜브 영상으로 37초와 40초 쇼츠 2개를 생성하고 각각의 SRT/TXT를 내보냈다. 게시 채널은 연결되지 않았고 외부 게시 기능은 실행하지 않았다.
- 공개 응답 HTML은 초기 Next.js 셸이었고, 로그인 후 렌더링 DOM에 템플릿 카드와 계정 화면이 있었다. 공개 정적 JS/CSS만으로 서버 모델·프롬프트·렌더링 파이프라인을 확정할 수 없다.

근거 파일과 테스트 입력·프로젝트 ID는 당시 작업 폴더의 `research/alphacut/REPORT.md`에서 찾는다. 원본 화면 덤프와 서명된 자산 URL은 공개 저장소에 포함하지 않는다.
