# 참고 영상에서 제작 구조를 찾아 중립 프롬프트로 쓰기

특정 제품의 구매를 권하거나 특정 서비스를 홍보하는 요청문이 아니다. 대괄호만 바꾸어 생활용품·전자제품·공간·교육 등 여러 소재에 적용한다. 고니 공개 스킬의 로컬 편집과 Higgsfield 생성 단계를 구분한다. 로컬 편집 엔진은 컷·자막·배속·고정 화면 합성을 맡고, 새로운 실사 동작 생성은 별도 모델이 맡는다.

## 이번 참고자료에서 가져올 것

- [장면별 변환 안내](https://dour-tailor-5c6.notion.site/41361c2773b180adbcc0e670efa2ef13): 촬영 → 장면 프레임의 선택 요소 편집 → 원본 영상과 참조 이미지로 변환 → 검수 후 출력이라는 순서를 참고한다. 원문의 홍보 문구나 프롬프트를 그대로 배포하지 않는다.
- [제품 설명 쇼츠](https://www.youtube.com/shorts/FNPMz_AV6eY): 진행자 정면과 손·제품·화면이 보이는 장면의 역할 분리, 짧은 자막과 한 번에 하나의 정보 전달을 참고한다. 표본 화면에서 확인한 구조다. 화면 속 제품 사양이나 성능은 새 제품에 옮기지 않는다.
- [뷰티 광고 참고 영상](https://www.youtube.com/watch?v=HnZi_XV_ztY): 약 1초의 붉은 공간과 흰 의상, 7초의 접촉 부위 근접 화면, 12초의 얼굴 근접 화면, 19초의 밝은 공간과 바닥 그림자를 표본으로 확인했다. 색상 대비·재질·빛·접촉·구도의 연결을 분석하는 참고이며, 출연자나 제품의 복제 요청이 아니다.

두 영상보다 좋은 결과를 목표로 하되 프롬프트 한 번으로 달성한다고 보장하지 않는다. 전체 동작과 실제 오디오를 검수하기 전에는 품질 우열·입싱크 합격을 확정하지 않는다. 원본 안내의 ‘항상 동일 결과’, ‘특정 구간 재편집’, ‘최대 길이’, ‘해상도별 배수’는 현재 도구에서 다시 검증한다.

## 1. Codex·Claude에 먼저 넣는 통합 요청문

```text
고니 GitHub의 goni-higgsfield-recast와 사용 가능한 로컬 영상 편집 스킬을 기준으로 작업해 줘.
아래 참고 영상에서 눈으로 확인한 제작 구조를 분석하고 내 소재에 적용할 중립적인 제작안을 만들어 줘.
리버스 분석은 장면·구도·빛·동작·전환·자막 타이밍을 정리하는 뜻이야. 비공개 AI 모델이나 원래 제작자의 비밀 프롬프트를 복원했다고 말하지 마.

내 소재: [제품 또는 공간]
실제 옵션·공식 정보: [링크와 확인한 사양]
사용할 인물·음성: [본인/사용 허락을 받은 자료]
원본 영상: [파일]
참고 영상: [링크]
유지할 것: [얼굴, 의상, 동작, 제품 형태 등]
바꿀 것: [배경 또는 소품]
최종 길이·비율: [길이 / 9:16 또는 16:9]
크레딧 한도: [C], 추가 결제 한도: [금액 또는 0]

1) 관찰 사실과 새 제안을 나누어 타임코드별 장면표를 만들어 줘.
2) 장면마다 보여 줄 정보는 하나로 줄이고, 원본 동작을 살리는 편집과 신규 영상 생성을 구분해 줘.
3) 촬영 지침, 이미지 편집 요청문, 영상 변환 요청문, 로컬 편집 지시, 검수표를 각각 작성해 줘.
4) 제품 성능·효능·사용 후기를 지어내거나 구매를 압박하지 마. AI로 만든 시연을 실제 제품 테스트라고 쓰지 마.
5) 원본에서 가장 어려운 5초를 먼저 골라 이미지 한 장·결과 한 개로 시험해 줘. 실제 지원 옵션과 비용을 확인한 뒤 허용된 예산 안에서 실행해 줘.
6) 참고 영상 이상의 완성도를 목표로 하되 손·제품·빛·접촉·장면 연결·음성을 비교한 증거와 남은 문제를 알려 줘. 실패 구간만 수정하고 성공 장면은 재사용해 줘.
7) 확정 후 자막·로고·화면 글자는 로컬 편집으로 넣고, 원본 음성을 결합해 싱크를 확인해 줘. 최종 MP4와 프롬프트·타임라인·비용·검수 기록을 함께 남겨 줘.
```

## 2. 촬영할 때 읽는 요청문

```text
[소재]의 [한 가지 동작]을 5초 동안 촬영할 수 있게 구도를 잡아 줘.
카메라를 고정하고 얼굴과 손, 물체가 서로 가려지는 구간을 줄여 줘.
교체할 물체는 실제 위치에 비슷한 크기의 대체 물체를 놓고 촬영해.
처음과 끝에 잠깐 멈추는 구간을 두어 다음 컷과 연결하기 쉽게 해.
빛은 [방향]에서 오도록 유지하고 자동 노출 변화와 흔들림을 줄여 줘.
제품을 설명한다면 실제 옵션만 읽고, 촬영하지 않은 결과나 효과는 말하지 마.
```

## 3. 캡처 이미지 편집 요청문

```text
첨부한 원본 프레임을 기준으로 [교체 대상]만 [새 대상]으로 바꿔 줘.
인물의 정체성, 피부 질감, 의상, 손가락 위치, 표정, 카메라 위치와 렌즈 느낌은 유지해.
새 물체의 크기·중심·기울기를 원래 물체에 맞추고 손가락이 앞뒤로 가리는 관계를 지켜 줘.
바닥과 손에 닿는 부분에는 주변 광원과 일치하는 접촉 그림자를 만들어 줘.
배경은 [공간], 주광 방향은 [방향], 색온도와 노출은 [기준 이미지]와 맞춰 줘.
관련 없는 소품·인물·글자·로고는 추가하지 마.
손이나 물체 형태를 자연스럽게 유지할 수 없다면 교체 범위를 더 단순하게 제안해 줘.
```

## 4. 원본 영상 변환 요청문

대괄호의 참조 이름은 업로드 후 화면에 표시되는 실제 이름으로 바꾼다. 아래 초는 예시이며 원본 장면표에 맞춘다.

```text
[원본 영상]을 움직임과 시간의 기준으로 사용해 줘.
길이와 비율은 원본을 유지해. 바꾸는 요소는 [배경]과 [지정 물체]뿐이야.

[0초~2초]: [참조 이미지 A]의 외관을 적용해. 원본 손의 시작 위치와 물체를 잡는 순간을 유지해.
[2초~4초]: 손과 물체가 붙어 움직이도록 해. 물체의 크기·두께·무게감이 달라지거나 손을 관통하지 않게 해.
[4초~끝]: 물체가 놓이는 위치와 바닥 접촉을 유지하고 다음 컷과 연결되는 자세로 마무리해.

전 구간에서 얼굴, 의상, 제품 외형, 카메라 구도와 동작 타이밍을 유지해.
장면 안에서 조명 방향·노출·색이 갑자기 바뀌지 않게 해.
예고 없이 물체가 사라지거나 생기는 현상, 손가락 수 변화, 경계 떨림, 배경 깜빡임을 억제해.
원본에 없는 대사·음악·자막·워터마크를 만들지 마.
원본 음성은 별도 보관하며 출력에서 보존 여부를 검수할 거야. 모델이 보존하지 못하면 편집 단계에서 원본 오디오를 결합해.
```

## 5. 새 광고형 장면을 만드는 요청문

원본 보존 편집과 별개인 신규 합성 장면용이다. 인물·공간·제품 자료를 직접 준비한다.

```text
[제품 또는 공간]을 보여 주는 사실적인 5초 장면을 만들어 줘.
이번 컷의 목적은 [질감 / 크기 / 사용 흐름 중 하나]를 보여 주는 것이야.
주인공은 [허락된 인물 또는 새 가상 인물], 동작은 [한 가지], 배경은 [장소]야.
빛의 방향은 [방향]으로 고정하고 제품의 모서리, 재질 반사, 표면 질감이 읽히게 해.
카메라는 [고정 / 느린 전진 중 하나]만 사용해. 불필요한 줌과 회전을 섞지 마.
손과 제품이 닿는 부분, 발과 바닥의 접촉, 그림자 방향이 물리적으로 이어지게 해.
제품 외형과 선택 옵션을 유지하고 새로운 버튼·성능·효능·인증 표시를 만들지 마.
로고·자막·화면의 정확한 글자는 비워 둬. 편집 단계에서 실제 자료로 넣을 거야.
참고 광고의 배우·브랜드·음악·문구를 복제하지 말고, 구도와 조명의 원리만 내 소재에 적용해.
```

## 6. 고니 로컬 편집·검수 요청문

```text
생성한 장면을 실제 재생하며 아래 항목을 시간과 함께 기록해 줘.
손가락과 접촉 / 제품 외형 / 얼굴 일관성 / 반사와 그림자 / 경계 떨림 / 장면 전환 / 음성 싱크 / 자막 가독성.
대표 프레임은 원본과 나란히 비교하고, 움직임은 시작부터 끝까지 정상 속도로 확인해 줘.
각 항목을 통과·수정·미검증으로 나누고, 미검증을 통과로 처리하지 마.
고니 로컬 편집 도구로 컷 연결·자막·원본 음성 결합을 처리해 줘.
고정 화면 합성은 실제 화면 네 모서리와 가림을 확인한 경우에만 사용해.
움직이는 카메라나 손이 화면을 가리는 장면은 추가 추적·마스킹이 필요하므로 고정 합성만으로 해결했다고 하지 마.
최종 해상도 확대 전에 형태와 움직임을 확정해. 업스케일은 잘못된 손이나 동작을 고치는 과정이 아니야.
참고 영상보다 나아졌다고 말할 때는 비교한 장면과 개선 항목을 적어 줘.
```

처음에는 ‘작은 물건을 들어 올렸다 내려놓는 5초’처럼 한 동작으로 시작한다. 복잡한 장면을 한 번에 넣기보다, 통과한 장면을 연결하면서 완성도를 높인다. 이 프롬프트는 제작 지침이며 아직 생성·검수하지 않은 결과를 보장하지 않는다.
