# 세 요금제와 노션 실습 횟수

2026-11-14 공식 한국어 요금표 확인. 연간 결제의 월 환산 표시이며 할인·세금·갱신액은 결제 직전 확인한다. 매달 아래 금액만 결제한다는 뜻이 아니다.

|---|---:|---:|---|
| Starter | US$19 | 270 | Seedance 2.5 미포함 표시. 크레딧만 나눠 실행 가능하다고 안내하지 않는다. |

직접 찍은 원본 + GPT Image 2 1k medium 9:16 참고 이미지(장당 1C) + Seedance 2.5 video_edit 480p의 MCP 사전 견적이다. 이미지와 영상 모두 첫 시도 성공, 음성 생성·업스케일·재생성 제외. 입력 영상 없는 조회이므로 실제 파일로 실행 전 재견적한다. 웹 일반 생성과 설정이 다르다.

| 구성 | 한 편 | Plus 30일 총 / 하루 평균 | Ultra 30일 총 / 하루 평균 |
|---|---:|---:|---:|
| 20초 + 이미지 3장 | 73C | 16편 / 0.53편 | 41편 / 1.37편 |
| 30초 + 이미지 3장 | 108C | 11편 / 0.37편 | 27편 / 0.90편 |
| 5초 시험 + 이미지 1장 | 19C | 63회 / 2.10회 | 157회 / 5.23회 |

하루 평균은 총편수를 30으로 나눈 운영 기준이지 일일 한도가 아니다. 5초 시험과 완성 영상 한 편을 섞지 않는다. 20초 매일 한 편은 73×30=2,190C로 Plus에는 부족하고 Ultra 기본에서는 재작업 전 810C가 남는다.

Ultra의 세 지급량 3,000/6,000/9,000C를 비교하면 20초는 41/82/123편(하루 평균 1.37/2.73/4.10), 30초는 27/55/83편(0.90/1.83/2.77). 6,000·9,000 옵션 금액은 따로 확인한다.

연간 구독은 1년에 한 번 결제하고 크레딧은 30일마다 자동 보충된다. 월간 구독은 매월 갱신 결제가 완료되면 새 크레딧을 받는다. 남은 구독 크레딧은 이월되지 않는다. 보충을 위해 매달 추가 팩을 살 필요는 없다. 먼저 소진하면 기다리거나 선택적으로 추가 팩을 구매하며 팩은 90일 유효하다. 팩만으로 미포함 모델이 열리지는 않는다. 실제 날짜는 프로필 → Manage Account → Subscription에서 결제 갱신일과 크레딧 보충일을 각각 확인한다.

공식 화면은 웹 무제한·무료 생성이 MCP/CLI·Canvas·Supercomputer에 적용되지 않는다고 안내한다. 오늘 Plus·Ultra Seedance 2.5 카드는 14일 혜택이다. 연간 구독이 모든 모델의 365일 무제한을 뜻하지 않는다. 대상 웹 작업의 0C 적용 시 위 계산에서 제외하지만 대기열·속도 제한 때문에 확정 일일 편수를 제시하지 않는다.
