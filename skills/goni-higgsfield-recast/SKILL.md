# 고니 힉스필드 반전 릴스

참고 원리: [릴스몬 제작 안내](https://dour-tailor-5c6.notion.site/41361c2773b180adbcc0e670efa2ef13). 장면별로 촬영 프레임을 변환한 이미지를 만들어 원본 영상과 함께 영상 편집 모델에 전달한다. 원문에 나온 시간·비용·품질은 보장이 아니라 예시다.

1. 원본 영상과 교체할 배경·물체, 유지할 얼굴·동작·음성, 원하는 비율을 확인한다. 촬영 전이라면 카메라를 고정하고 바꿀 물체를 실제 위치에 두도록 제안한다. ffprobe 등으로 길이와 오디오를 확인하고 장면 변화 시각을 기록한다.
2. 각 핵심 구간의 프레임을 추출하고 이미지 편집 도구로 대상만 바꾼다. 인물의 자세·카메라 구도와 구간별 배경·조명 일관성을 유지한다. 이미지 번호와 해당 타임코드를 표로 기록한다. 인물과 자산 사용 권한은 요청 맥락에서 확인한다.
3. 현재 사용자가 지정한 계정·브라우저·비용 한도를 따른다. 로컬에 `higgsfield-project-ops`가 있으면 해당 사용자의 설정을 참고하고, 없으면 이 스킬만으로 진행한다. 다른 사람의 이메일이나 PC 경로를 가져오지 않는다. 사용 가능한 Seedance 영상 편집 모드, 영상과 이미지 참조 입력, 길이, 해상도, 실제 가격을 현재 화면에서 확인한다. MCP 모델 정보는 별도 계정의 읽기 정보일 수 있으며 웹 혜택과 동일하다고 추정하지 않는다. 480p는 지원될 때 시험 선택지다. 예산 미지정 시 추가 크레딧 0으로 준비하고 유료 전환을 자동으로 하지 않는다.
4. 원본 영상과 순서가 확인된 이미지들을 넣고, 실제 UI에서 표시하는 참조 이름을 사용해 구간별 변경과 유지 대상을 지정한다. 비율은 원본에 맞춘다. 원본 음성은 별도로 보관하고 재합성 없이 유지하도록 요청하되 모델이 이를 보장한다고 가정하지 않는다.
5. 결과를 실제 재생해 얼굴, 손, 물체 접촉·그림자, 장면 전환, 입모양과 음성을 확인한다. 필요하면 원본 오디오를 로컬 편집에서 다시 결합하고 싱크를 점검한다. 특정 구간만 재편집 가능한지는 현재 화면에서 확인한다. 확정 후 지원되는 업스케일 비용과 조건을 확인하고 최종 출력한다.

## 프롬프트 골격

`원본 영상의 인물, 의상, 구도와 동작 타이밍을 유지한다. [시작–끝]에는 [참조 이미지 번호]의 [배경·소품]을 적용한다. [다음 구간]에는 [참조 이미지 번호]를 적용한다. 배경과 조명은 장면 간 일관되게 유지한다. 원본에 없는 인물, 텍스트, 워터마크는 추가하지 않는다.`

구간·참조명·교체 대상은 실제 입력을 기준으로 채운다. 결과가 원본 음성이나 입모양을 완전히 보존했다고 검수 없이 주장하지 않는다. 제작 완료 보고에는 모델·모드·입력 순서·길이·비용·결과 파일과 미검증 항목을 적는다.

## 다른 PC와 Codex·Claude에서 사용

이 폴더의 SKILL.md와 references를 함께 설치한다. 파일 접근이 가능한 에이전트는 현재 환경의 스킬 설치 위치와 문법을 확인해 저장하고, 일반 채팅 환경이라면 설치용 파일을 제공한다. 설치만으로 Higgsfield 로그인, 생성 권한, 비용 혜택이나 로컬 영상 도구가 생기는 것은 아니다. 필요한 도구가 없으면 가능한 기획·프롬프트까지 만들고 정확한 미완료 항목을 알린다.

설치 후 호출 예: `고니 힉스필드 반전 릴스 스킬로 이 영상의 배경과 컵만 바꿔 줘. 동작과 음성 유지, 9:16, 추가 크레딧 0.`

새 예시와 자연스러운 접촉을 시험할 때 [참조 프롬프트](references/natural-recast.md)를 읽는다. 원본이 없으면 사용자의 새 예시 생성 요청을 확인한다. 단순한 동작부터 기준 영상을 만든 다음 실제 프레임으로 변환 이미지를 만든다. 별개로 생성한 두 영상을 원본 동작 보존 시험이라고 보고하지 않는다.

동시 생성 제한이 나오면 기존 작업의 ID와 상태를 기록한다. 다른 작업을 임의 취소하거나 유료 경로로 바꾸지 않는다. 새 작업이 거절됐으면 접수 또는 완료라고 보고하지 않는다.

## 노션·교육자료 인계

사용자가 요청한 경우 최종 검수 영상에 맞춘 썸네일, 실제 사용 프롬프트, 공개 스킬 링크와 입력 양식을 노션에 함께 정리한다. 실제 결과와 기획 이미지를 구분한다. 카페 등 게시 대상과 권한이 지정된 경우 해당 부서에 최종 자료와 사용 순서를 전달하고 결과 URL을 확인한다.
