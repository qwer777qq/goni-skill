# 고니 로컬 제품 영상 CLI

사용자 소유 제작 소스에서 확인한 편집 동작을 독립 구현했다. 생성형 모델·유료 API·클라우드 자동 전환은 없다. [설치와 명령](references/cli.md), [기능·검증 범위](references/validation.md), [원본 스타일 근거](references/verified-style.md)를 필요한 단계에서 읽는다.

## 제작

1. 정확한 상품 URL·선택 옵션·참고 미디어·얼굴/음성 사용 범위·최종 길이와 배속을 확인한다. 사진의 홍보 문구와 실제 판매 옵션이 다르면 선택 옵션을 기준으로 설명한다.
2. `studio.py doctor`로 FFmpeg·Python 패키지를 확인한다. OFL 폰트 13개가 라이선스와 함께 포함돼 있다. `fonts`·`presets` 명령으로 폰트와 효과를 확인한다. API 키·개인 미디어·작업 영수증을 공개 저장소에 넣지 않는다.
3. 질문 → 실제로 보여 줄 자료 → 조건별 선택 기준으로 구성한다. 검색 API가 연결돼 있으면 실제 수치·조회시각·실패를 별도 기록한다. 월간 검색량을 실시간 급등으로, 댓글의 주장을 제품 성능으로 바꾸지 않는다. 검색 이유는 추론이다.
4. 원본 영상이 있으면 `render`, 제품 사진과 설명·음성이 있으면 `cards.py`로 사진·도해형 영상을 만든다. **사진 설명형 출력은 새 실사 장면 생성이나 실기 구동 촬영이 아니다.** 촬영하지 않은 손동작·게임 FPS·발열·처리 시간을 만들어 넣지 않는다.
5. 고정 카메라의 화면 교체는 `compose-screen`으로 한다. 실제 프레임에서 화면 네 모서리와 가릴 수 없는 부분을 정한다. 움직이는 카메라나 손이 화면을 가리는 장면은 이 합성기의 검증 범위 밖이다.
6. 원음 시간차 조사에는 `align-voice`를 쓰되 같은 대사인지 먼저 확인한다. 출력은 후보 시간표이며 입싱크 합격 판정이 아니다. 새 설명이 필요하면 별도 녹음이나 `narrate`의 설치된 Windows 음성을 사용한다. 기본 TTS는 본인 목소리 복제가 아니다.
7. `render`는 영상·음성·자막 시간에 같은 배속을 적용한다. 1.4배속 최종 50초는 유효 원본 최소 70초가 필요하다. 단순 반복·무의미한 정지 화면으로 길이를 채우지 않는다.
8. `inspect --decode`와 `frames`로 파일·자막·합성 경계를 확인한다. 실제 청취·연속 모션·입싱크 검수 여부를 별도 기록한다. 구조 검사 통과만으로 자연스러움이나 참고 광고 이상의 품질을 주장하지 않는다.

## 전달

출력 MP4, 타임라인 JSON, ASS, 생성/렌더 로그, 출처·검수 기록을 함께 보관한다. 사용자가 요청한 GitHub·노션·카페에만 게시하고 실제 URL과 원격 커밋을 확인한다. 강의에는 전체 스킬 폴더 또는 전체 파일 복원 자료를 제공한다. SKILL.md 한 장만 붙여 넣었다고 CLI 파일까지 설치됐다고 말하지 않는다.

Seedance의 비공개 가중치·서버 추론 코드는 확보하지 않았으며 이 패키지는 Seedance 복제본이 아니다. 기존 Higgsfield 유료 예제는 별도 이력으로 구분한다.
