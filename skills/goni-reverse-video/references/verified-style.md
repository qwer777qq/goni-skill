# 원본 제작 파일로 확인한 구조

대상: 사용자 쇼츠 https://www.youtube.com/shorts/FNPMz_AV6eY

2026-11-14 사용자 로컬 제작 프로젝트의 `paid_prompt.txt`, `finish_v18.py`, `captions.ass`, `edit_plan.json`, `voice_alignment.json`, 게시 결과 기록으로 연결을 확인했다. 완성 영상만 보고 폰트를 추측한 것이 아니다.

| 항목 | 확인 내용 |
|---|---|
| 실제 자막 폰트 | Paperlogy 7 Bold, 1080×1920 기준 80px |
| 색상 | 흰색, 강조 #FFF59A, 외곽선 #202020 3px, 그림자 1.5 |
| 위치 | 가운데 x=500, 장면별 y=1100/1600/210/870 |
| 효과 | 100ms 페이드, 94→103→100% 크기 변화(0/120/200ms) |
| 생성 원본 | 본인 얼굴·제품·원음 참조를 사용한 30초 유료 생성 |
| 구도 | 정면 상반신 → 제품과 손 → 제품 상세 → 정면 판단 |
| 오디오 | 원음 구간별 시간 정렬 후 영상과 합성 |
| 후반 작업 | 생성물에 자막·강조 효과를 별도 합성 |

새 CLI는 자막·편집 구조를 독립 구현한다. Paperlogy 9 Black 파일도 원본 폴더에 있었지만 실제 Caption 스타일은 7 Bold다. 기존 영상의 16형/M5 Pro/24GB/1TB 옵션은 새 상품에 복사하지 않는다. 얼굴·음성·유료 생성 미디어는 공개 패키지에 포함하지 않는다. 재배포 가능한 OFL 폰트는 원본 라이선스와 함께 포함한다.

## 추가한 폰트와 텍스트 효과

Paperlogy 9개 굵기, Pretendard Regular/Bold/Black, Do Hyeon Regular 총 13개 파일을 포함한다. Paperlogy는 기존 설치된 수정하지 않은 파일, Pretendard는 공식 저장소의 고정 커밋, Do Hyeon은 Google Fonts 공식 저장소에서 가져왔다. 파일별 출처·SHA256·라이선스는 `assets/fonts/manifest.json`에 있다. Paperlogy와 Pretendard는 한글 완성형 11,172자, Do Hyeon은 2,437자를 포함하므로 드문 한글은 다른 폰트를 사용한다.

정지, 페이드, 원본 팝, 위로 슬라이드, 옆으로 슬라이드, 줌, 바운스, 타자기 효과를 구현했다. 원본 팝 외의 효과는 이번에 독립 구현한 확장이다. Seedance 내부 효과를 추출했다고 표현하지 않는다.

원본이 유료 모델로 생성됐다는 사실은 이 편집 CLI가 같은 실사 영상을 생성할 수 있다는 근거가 아니다. 이 패키지는 모델을 포함하지 않으며, 준비된 영상·사진·음성을 편집한다.
