# 납품과 검수

납품은 원본 참조·컷 목록·자막/강조·템플릿 매핑·미확인 항목·수정 가능한 프로젝트·완성 영상·썸네일 원본·제목/본문/챕터/하이라이트를 같은 회차 폴더에 연결한다. 요청하지 않은 업로드를 하지 않는다.

| 검사 | 합격 근거 | 불합격 시 |
|---|---|---|
| 시간 | 실제 fps와 프레임 정수, 컷 후 자막 매핑, 마지막 프레임 이내 | 매핑 수정 후 재생 |
| 의미 | 훅의 주장과 원본 발언·시범·결과가 일치 | 후보 교체/문구 완화 |
| 인물·동작 | 얼굴·손·클럽·공 경로가 글자/크롭에 가리지 않음 | 위치/크기/시점 조정 |
| 스타일 | 기존 타이틀 seed와 폰트·모션·박스 일치, 장르별 선택 | 추정값을 확정값으로 승격하지 않기 |
| 경기 정보 | 홀·PAR·거리·이름·타수 원자료 확인 | 미확인 표시, 자동 확정 금지 |
| 편집 가능성 | 텍스트 직접 수정, 저장·재열기, 원본 미디어 연결 | 구워진 자막을 완료로 보고하지 않기 |
| 렌더 | 실제 파일 존재·길이/해상도/fps·끝까지 디코딩·소리·표본 프레임 | 실패 원인을 남기고 수정 |
| 전체 검수 | 전체 시청/청취 완료 여부를 별도로 기록 | 표본 검수를 전체 검수라 부르지 않기 |

첫 사용 시 일반 요약, 응답, 강조, 손글씨, 점수판, 가장 긴 문장, 공 추적을 작은 샘플로 검증한다. 정확한 기존 Motion seed가 없으면 스타일 일치 검수는 대기다. 시험 렌더의 성공 범위를 본편 제작 완료로 확대하지 않는다.
