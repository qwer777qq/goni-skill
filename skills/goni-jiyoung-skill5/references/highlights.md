# 하이라이트 선정과 시간축

원본 프레임의 source_in/source_out(끝 제외)을 기록하고 최종 타임라인 위치를 별도로 계산한다. 발화 강도만으로 점수화하지 않는다. 문제·설명·동작·결과·반응이 있어야 독립 클립이 된다. 공의 결과를 숨기는 훅은 허용해도 없던 결과를 만들지 않는다.

레슨: 실수 발견→왜 그런지→한 가지 교정→전후 비교. 코스: 홀·목표→선택 이유→샷→결과. 대결: 현재 점수→차례→결정적 샷→정지/판정→반응. 공지: 공지 이유→검증된 내용→조건·안내.

시작·끝은 자동 전사와 표본 프레임으로 잡은 후보다. 영상 단위 전체 시청·청취나 정확한 최종 프레임 컷을 완료했다는 의미는 아니다. 기존 방송 자막이 구워진 참고 영상에서 자막을 중복 생성하지 않는다. 실제 제작에는 해당 회차의 원본 소스와 전사를 사용한다.

하이라이트 기록 필드: source_id, in_frame, out_frame, 장르, 훅, 상황, 시범, 결과, 반응, subtitle_role, 보호 대상, 확인 상태, 선택 이유. 탈락 이유도 기록하면 다음 회차에 같은 오류를 줄일 수 있다. 사람이 선택한 결과를 누적하되 다른 촬영본의 타임코드는 재사용하지 않는다.
