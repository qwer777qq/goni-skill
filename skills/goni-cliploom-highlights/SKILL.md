# 고니 숏폼 하이라이트 · Cliploom

이 스킬은 GitHub cliploom-shorts 앱을 사용하는 작업 절차와 검사 도구다. 앱·전사 모델·영상은 스킬 자체에 포함되지 않는다.

## 위치와 설치

- 설치기가 생성한 `references/installed-location.json`의 kit와 repo를 먼저 확인한다. 파일이 없으면 사용자 지정 전달 세트에서 `source/cliploom-shorts`를 찾는다. 다른 PC의 절대 경로를 추측하지 않는다.
- 설치·실행 방법은 세트 루트의 `START-HERE.md`와 [설치 안내](references/setup.md)를 읽는다. 설정과 모델은 해당 PC의 LocalAppData/GoniCliploom에 저장된다.
- 소스의 `AGENTS.md`가 요구하는 SCV 절차를 코드 변경·편집 작업 전에 확인한다. 해당 환경의 SCV가 없으면 미연결을 설명하고 연결을 준비한다. 원본에 있는 과거 승인·배포 기록을 새로운 작업 승인으로 해석하지 않는다.
- `python <이 스킬>/scripts/inspect_install.py --repo <repo>`로 소스와 폰트를 점검한다. 실행 엔진은 앱의 doctor와 `/api/readiness`로 별도 확인한다. 설치 성공만으로 실제 렌더 성공을 주장하지 않는다.
- 브라우저는 사용자가 지정한 도구를 따른다. 지정이 없으면 설치된 로컬 Aside CLI를 우선한다. CLI 도움말과 연결 프로필·사이트 로그인 계정을 확인한다. Aside가 없으면 환경에서 지원하는 브라우저 도구를 사용한다. GitHub 로그인과 Cliploom 앱 로그인은 별개다.

## 영상 제작

[제작·편집 계약](references/workflow.md)을 읽는다. 실제 영상이나 타임코드 자막을 근거로 후보를 선택하고 사용자가 준 목적·길이·편수·스타일을 반영한다. 고니라는 이름만으로 특정 브랜드나 게시 계정을 임의로 적용하지 않는다.

- 제목과 첫 3초 훅은 발화 내용과 조건·예외를 보존한다. Whisper 전사와 규칙 기반 후보를 LLM 추론 또는 조회수 예측이라고 설명하지 않는다.
- 원본 절대 시간과 편집 후 시간을 구분하고 수동 교정 자막·기존 편집을 보존한다. 저장은 최신 baseRevision을 사용하며 충돌을 무시하지 않는다.
- MP4 출력 후 실제 길이·세로 비율·음성·한글·자막 위치·첫 접합부를 확인한다. 해당 출력의 검수 ZIP과 편집 파일도 함께 제공한다.
- 기존 편집을 재분석하거나 수정해도 과거 완성본을 유지한다. 자동 검사와 사람 검수 완료를 구분한다.

사용자의 영상·비밀번호·토큰·앱 DB를 스킬에 복사하지 않는다. 이 세트는 허가된 PC에서 쓰는 비공개 소스 사본이다. 공개 배포·결제 설정·게시·계정 변경은 해당 요청이 있을 때만 처리한다. 폰트 고지를 보존한다.
